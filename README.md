# FinDA — KOSPI200 급등종목 과열위험 조기진단 모델

> **“급등은 매수 신호가 아니라 관찰의 시작일 수 있다.”**
> 

관심이 몰리면서 급등한 종목을 개인투자자가 마주했을 때, 지금 추격 진입해도 되는지 판단하는 데 참고할 수 있는 **조기진단 모델**을 만든 프로젝트입니다. 자동매매 전략이 아니라, 급등 이후 실제 가격·거래량 움직임을 며칠 관찰하며 위험 판단을 갱신하는 **의사결정 보조 도구**를 목표로 했습니다.

---

## 1. 문제의식

주식 커뮤니티·검색·뉴스에서 급등 종목을 마주하면 누구나 비슷한 고민을 합니다.

- “지금 안 사면 더 오르는 것 아닐까?” (FOMO)
- “사람들이 이미 다 알 정도면 고점인 것 아닐까?” (고점 공포)

이 프로젝트는 이 고민을 데이터 문제로 바꿨습니다.

> **“사람들의 관심이 급증한 종목은 이후에도 상승하는가, 아니면 이미 과열된 고점인가?”**
> 

분석 대상은 2021년 이후 KOSPI200 Historical 구성종목(260종목)이며, 최종 모델링에는 약 1,250건의 급등 사건을 사용했습니다.

---

## 2. 데이터

| 데이터 | 출처 | 비고 |
| --- | --- | --- |
| 주가·거래량·투자자별 수급 | pykrx (KRX) | 개인/외국인/기관 순매수, 시가총액, PER/PBR 등 |
| 검색 관심지표 | Naver DataLab | 종목별 대표 검색어 그룹 구성 |
| 뉴스 관심지표 | BigKinds API | 동음이의어·계열사명 필터링 처리 |
| 공매도 데이터 | pykrx | 공매도 금지기간(2023.11~2025.03) 별도 flag 처리 |

**급등 Event 정의**: 20거래일 수익률 ≥ 20% AND 당일 거래량/직전 20일 평균 ≥ 1.5, KOSPI200 구성종목, 20거래일 cooldown 적용

데이터 저장·적재 파이프라인(GCS Parquet + DuckDB SQL 계층)을 구축했고, 이를 활용해 **가설검증·모델링·데이터 수집**을 주도했습니다.

---

## 3. 시행착오 — 이 프로젝트의 핵심

처음 세운 가설을 그대로 증명한 프로젝트가 아니라, **가설 실패와 데이터 이슈를 하나씩 발견하고 수정하며 연구질문을 정교화한 과정** 자체가 결과물입니다.

```
"관심이 몰리면 급등이 지속되는가?" (가설)
        ↓
검색·뉴스 관심지표는 급등 형성과는 관계 있었지만
이후 경로 예측력은 약함 (EDA 단계 확인)
        ↓
5개 유형(지속상승/관망/과열반전 등) 분류 시도
→ 라벨 정의 10종 × 알고리즘 3종, macro AUC 0.45~0.61 (랜덤 수준)
→ "관망형↔지속상승형" 혼동이 모든 조합에서 구조적으로 반복
        ↓
매수/회피 이진분류(EWMA 장벽전략)로 단순화
→ "이거 퀀트 매매전략 아니냐" 자기반성, 본래 목적 재점검
        ↓
Peak Give-back(상승 후 반납)으로 과열을 직접 정의
→ 사건일(T) 시점 예측 시도, precision 0.62~0.70대 확보
        ↓
Feature Importance 재검증 중 vol_sustain 계열 변수가
사건일 이후 정보를 사용한 Data Leakage였음을 발견
→ 리크 제거 후 재검증: precision 0.70→0.47, recall 0.59→0.24로 대폭 하락
        ↓
"사건 당일 예측"에서 "사건 이후 초기 반응 관찰"로 문제 재정의
→ Prediction Cutoff를 T → T+3 → T+5 → T+7 → T+10으로 이동
        ↓
Direct T+20 BHAR(train-fold 내 하위 35%) 로 Target 최종 단순화
→ T+5 조기진단 모델 AUC 0.78~0.79 확보
```

## 4. 최종 모델

**질문**: “급등 후 T+5(5거래일)까지의 초기 행동을 봤을 때, 이 사건이 T+20 시점에 시장 대비 상대적 부진군으로 끝날 위험이 높은가?”

- **모델**: RandomForest, 5-fold walk-forward + SMOTE, 확신도 기반 선택적 출력
- **피처**: 사건일까지의 정적변수 13개(수익률·변동성·거래량 등) + T~T+5 초기반응 동적변수 6개 (관심·수급·공매도는 최종 성능 개선에 유의한 기여 없음을 확인)

| 검증 구간 | AUC | Precision | Recall | F1 |
| --- | --- | --- | --- | --- |
| DEV (2021~2024, walk-forward) | 0.781 | 57.3% | 80.3% | 66.9% |
| 2025 (미래 구간 검증) | 0.787 | 54.5% | 70.9% | 61.7% |
| 2026 Stress (변동성 높은 구간) | 0.778 | 52.1% | 76.0% | 61.9% |

> 급등 사건 발생 후 T+5까지 관찰했을 때, 실제로 T+20 시점에 부진했던 사건의 71~76%를 놓치지 않고 탐지했고, “위험하다”고 경고한 사건 중 52~55%가 실제로 위험한 사건이었습니다.
> 

**왜 T+5가 메인인가**: 관찰기간을 늘릴수록(T+7, T+10) AUC는 계속 오르지만, T+5→T+7 구간의 개선폭은 통계적으로 뚜렷하지 않았던 반면(paired bootstrap p=0.397), 진단은 최대한 빨라야 실용적 가치가 있다고 판단해 **T+5를 메인 조기진단, T+7/T+10을 보완진단**으로 사용하는 다단계 구조를 채택했습니다.

## 5. 한계

- 검색·뉴스 관심지표는 “관심의 크기”만 측정하고 긍정/부정 방향성은 구분하지 못함 (감성분석 미수행 — 후속 검증 필요)

- Precision 52~55% 수준은 실무 적용 시 절반 가까운 오탐을 감수해야 함
- T+20 특정 시점 스냅샷 방식이라, 그 이후 다시 무너지는 “지연된 위험”은 놓칠 수 있음
